

| Commands | Description                                             |
| -------- | ------------------------------------------------------- |
| `ls`     | listing (used to list files in current directory)       |
| `cd`     | change directory                                        |
| `cat`    | concatenate ( ==use to read the content of the file== ) |
| `pwd`    | print working directory                                 |
|          |                                                         |

#### `cat`


>to see the contents of text files using a command called "**cat".**

![[Pasted image 20260104151126.png]]

Sometimes things like usernames, passwords (yes - really...), flags or configuration settings are stored within files where "cat" can be used to retrieve these.

>[!tip]
>*we can also read content of the file without navigating to it using cat command followed by the path of the file*
> `cat folder4/note.txt`
>	 
>![[Pasted image 20260104152434.png]]
