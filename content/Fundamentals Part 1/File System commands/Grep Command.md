==grep = search tool==

it like **Ctrl + F for terminal files**.

```shell
grep "something" filename
```

Search **every line** in `filename`  
If a line contains `"something"`  
→ **print that line**

>[!important]
>**grep does not modify the file**  
It only **reads** and **prints matching lines**
