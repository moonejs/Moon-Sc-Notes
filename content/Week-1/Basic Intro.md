
### shell

A **shell** is the **program inside the terminal** that:

- Reads your command
    
- Understands it
    
- Sends it to the OS


### Bash = Bourne Again Shell

- Most common shell in Linux
    
- Default shell in Ubuntu



### WSL

Windows Subsystem for Linux


```
Hardware

Operating System
   ├── Windows
   │    ├── CMD

   │         └── Ubuntu (Linux)
   │              └── Bash
   │
   └── Linux (real install)
        └── Ubuntu
             └── Bash

```
