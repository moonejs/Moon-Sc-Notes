It is a **secure way to connect to another computer over a network** (usually over the internet) and **control it using the terminal**.

>SSH = safely logging into another computer and using its terminal from your own machine

- Everything is **encrypted**
- any data sent between the devices is encrypted when it is sent over a network such as the internet

The syntax to use **SSH** is very simple.

1. The IP Address of the remote machine
2. Correct credentials to a valid account to login with on the remote machine.

```shell
ssh username@ip_address
```
